This dashboard works with anyone's /IOTCONNECT account. Sign in with your own solution key, environment, email and password.

The solution key and your password go straight to this dashboard's own backend over HTTPS, never to a third party. The password is traded once for a session token; the solution key is resent with every request, so it stays in this tab's session storage (or this browser's local storage, if you check the box above) while you're signed in. Use a private window on a shared computer.
